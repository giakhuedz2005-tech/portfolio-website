# Portfolio Website

Personal portfolio website for Gia Khue, an aspiring QA Tester. The site presents an introduction, testing-focused skills, project work, and contact information.

## Built with

- HTML5
- CSS3
- Themify Icons

## Run locally

Clone the repository, then open `index.html` in any modern web browser. No build step or dependency installation is required.

## Project structure

```text
index.html        Main page
asset/css/        Stylesheets
asset/img/        Portfolio images
asset/fonts/      Themify icon font files
```
